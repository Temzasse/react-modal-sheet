In addition to the `Sheet.Backdrop` it's possible to apply a scaling effect to the main app element to highlight the modality of the bottom sheet. This effect mimics the [iOS Modal View](https://developer.apple.com/design/human-interface-guidelines/ios/app-architecture/modality/) presentation style to bring more focus to the sheet and add some delight to the user experience.

| ![iOS Modal Effect Demo 1](/react-modal-sheet/media/example-apple-music.gif) | ![iOS Modal Effect Demo 2](/react-modal-sheet/media/example-snap-points.gif) |
| :--------------------------------------------------------------------------: | :--------------------------------------------------------------------------: |

To enable this effect you can provide the id of the root element where your application is mounted:

```tsx
function Example() {
  return <Sheet modalEffectRootId="root">{/*...*/}</Sheet>;
}
```

<Aside type="caution" title="Limitations">

Since the effect is applied to the root element it will NOT work as desired if the HTML body element is scrolled down at all. One way to avoid this is to use something like `height: 100vh;` and `overflow: auto;` on the root element to make it fill the whole screen and be scrollable instead of the body element. You can check the example apps [root styles](https://github.com/Temzasse/react-modal-sheet/blob/main/docs/src/examples/index.css) for a working example of this.

</Aside>

### Controlling the effect

You can control the start threshold of the effect with the `modalEffectThreshold` prop which should have a value between `0` and `1` representing the fraction at which the effect starts relative to the dragging distance. So for example, a value of `0.5` means the effect will start when the sheet is dragged halfway and `0.7` would mean the effect will start when the sheet is dragged 70% of the way to the top. The default value is `0` which means that the effect will start as soon as the sheet is opened or dragged into view.

<Aside type="note">

If you are using `snapPoints` the start threshold is calculated based on the
second snap point so that when the sheet is snapping to the first snap point,
meaning the sheet is fully open, the effect will only apply for that snap point
range and not for the whole draggable distance.

This gives a more natural UX and follows the native iOS effect more closely.

You can still override this behavior by providing a custom `modalEffectThreshold` value.

</Aside>

### Stacking sheets

The modal effect can also be applied to another sheet which lets you stack sheets on top of each other. Give the underlying sheet an `id` and use it as the `modalEffectRootId` of the sheet that is opened on top of it. You can stack as many sheets as you want by always pointing `modalEffectRootId` to the sheet directly underneath.

```tsx
function StackedExample() {
  const [isOpen, setOpen] = useState(false);
  const [isStackedOpen, setStackedOpen] = useState(false);

  return (
    <Sheet
      id="parent-sheet"
      isOpen={isOpen}
      onClose={() => setOpen(false)}
      modalEffectRootId="root"
    >
      <Sheet.Container>
        <Sheet.Content>
          <button onClick={() => setStackedOpen(true)}>
            Open stacked sheet
          </button>

          <Sheet
            isOpen={isStackedOpen}
            onClose={() => setStackedOpen(false)}
            modalEffectRootId="parent-sheet"
          >
            <Sheet.Container>{/*...*/}</Sheet.Container>
            <Sheet.Backdrop onTap={() => setStackedOpen(false)} />
          </Sheet>
        </Sheet.Content>
      </Sheet.Container>
      <Sheet.Backdrop onTap={() => setOpen(false)} />
    </Sheet>
  );
}
```

<Aside type="note">

The stacked sheet should be rendered inside the underlying sheet (like above) so that it is mounted after it and placed on top of it. Give the stacked sheet a tappable `Sheet.Backdrop` so that the underlying sheet can't be tapped or dragged while the stacked sheet is open. Note that a stacked sheet is unmounted without a closing animation when the underlying sheet is closed.

</Aside>

See the [Stacked sheets example](/react-modal-sheet/playground/stacked-sheets/) for a working example of this.
